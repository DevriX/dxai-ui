# DXAI-UI

WordPress plugin that converts **Figma**, **Lovable**, and **generated frontend ZIPs** (HTML/CSS/JS, Vue, React, Next.js) into native Gutenberg structures — headers, menus, heroes, blogs, forms, sliders — routed through Claude, OpenAI, Grok, or DeepSeek.

- Skill for agents: `.cursor/skills/dxai-ui/`
- Plan: `docs/PLAN.md`
- Research: `docs/RESEARCH.md`
- Local WP: `docs/LOCAL-WP.md`

## Requirements

PHP 8.2+, WordPress 6.4+.

## Local development

This repo is the plugin. Junction it into Local:

`C:\Users\DevriX\Local Sites\DXAI-UI\app\public\wp-content\plugins\dxai-ui`

WP admin: `http://dxai-ui.local/wp-admin/admin.php?page=dxai-ui`  
Default Local WP user: `admin` / `dxaiadmin`
